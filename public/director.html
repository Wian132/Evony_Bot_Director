Wake Claude on an attack

    

      When an account gets a real attack — one at or above the city’s defensepolicy /junktroop
      (1000 when not set; an army of unknown size counts) — the Director runs Claude once for that attack,
      on your own Claude login, with only the OTTObot tools. Its job is only to keep the account alive, and it can act
      only through the boxes below; with all of them off it still looks and reports. Waves of the same attacker within
      15 minutes are one attack. The Director checks the consoles once a minute.

  Uptime probes
  

    One line per bot console: name http://host:port.

    The Director asks each one every minute. This costs no game traffic — it is a local HTTP call — so it is safe while the game poller stays slow.
  

  
  

    
    
  




  Columns
  
Tick what the table shows, and drag a row to move
    its column (or drag a header in the table itself). Click any header to sort by it.

  

  

    
    
    
    
  




  Proxy list
  

    One per line. Paste straight from your provider — these all work:

    host:port ·
    host:port:user:pass ·
    socks5://user:pass@host:port ·
    http://host:port

    Bare host:port is treated as socks5. Blank lines and # comments are ignored.
  

  
  

  

  

    
    
    
  




  Start-up parameters for every account
  

    NEAT's Custom Parameters: every console gets them when it starts, and an account's own
    (✎ → Start-up parameters) win over them. -name value, one a line or several on one.
    Applies from each console's next start, never to a running one.
  

  
  
  
  

    What an OTTObot console does with NEAT's parameters:
    -autoscripts 1|0 autorun scripts ·
    -runscript File.txt the file each city runs first (from scripts\, else AutoRunScript.txt) ·
    -autorun 0 the engine starts paused ·
    -maxtrade N the most one script order may be for ·
    anything else, e.g. -teleport tuscany, reaches scripts as Config.teleport.
    Login, server and proxy are each account's own fields, never parameters.
