Where
123,456, or one of your cities by name: reinforce Fla, transport "Home City" t:20 wood:100k (quotes when the name has spaces).
Heroes
Wian by name · any first idle · any:level<500,attack>400 filtered (level / attack / politics / intel). Attack and scout need one. Reinforce and transport don't: write none or leave it out, and no hero is sent.
Troop codes
wo worker · w warrior · s scout · p pike · sw sword · a archer
t transport · c cavalry · cata cataphract · b ballista · r ram · cp catapult
Map memory
node mapscan.js scans the world into mapcache.json (the server caps each request at 20×20, so it tiles and pipelines). Then find Bob here — or node mapscan.js --find Bob — answers in milliseconds with no login.
Hero points
levelup Eli levels the hero then spends every unspent point on his dominant attribute — an attack hero gets attack, a politics hero gets politics. Override with levelup Eli intel, or do the whole city with levelup all. Attack = power, politics = management, intel = stratagem.
Prerequisites
build / upgrade check requirements first and name what is missing (“needs Town Hall level 2, you have 1”). Failures also show the game's own message. Tick auto-queue to have a missing building upgrade queued for you — it takes real build time, so re-run the line once it finishes.
Timing
@07:00:00.500 sets camp time so the wave lands then. Camp time is whole seconds; the sub-second part is handled by delaying the send.
